# Личный капитал — учебная платформа

Демонстрационный каркас первого этапа платформы «Личный капитал»: регистрация с подтверждением email, вход, восстановление пароля, профиль пользователя, административный раздел и очереди уведомлений.

Стек: **Laravel 13, PHP 8.3, Vue 3, Inertia.js, PostgreSQL, Redis, Docker**.

## Реализованная функциональность

| Раздел | Реализация |
|---|---|
| Регистрация и вход | Модальное окно входа и регистрации, подтверждение email, восстановление пароля, демонстрационная капча и ограничение частоты запросов |
| Профиль | Контактные данные, сведения о семье и работе, текстовые блоки, шкала активного дохода, индикатор заполненности, экспорт и удаление данных |
| Административный раздел | Список пользователей, блокировка и удаление, создание пользователей, журнал действий, уведомление администратора о регистрации |
| Интеграции | Единый сервис уведомлений, очереди Redis, раздел настроек интеграций с тестовой отправкой |
| Тестирование | Функциональные тесты регистрации, аутентификации, профиля, административного раздела и прав доступа |

## Требования для локального запуска

- PHP 8.3 или новее;
- Composer;
- Node.js 20 или новее и npm;
- PostgreSQL;
- Redis;
- PHP-расширения, необходимые Laravel и выбранной базе данных.

## Локальная установка

```bash
git clone https://github.com/Kratos31071992/lichny-kapital.git
cd lichny-kapital
composer install
cp .env.example .env
php artisan key:generate
npm install
```

В `.env` настройте подключение к PostgreSQL:

```dotenv
APP_URL=http://127.0.0.1:8000

DB_CONNECTION=pgsql
DB_HOST=127.0.0.1
DB_PORT=5432
DB_DATABASE=kapital
DB_USERNAME=kapital
DB_PASSWORD=secret

QUEUE_CONNECTION=redis
REDIS_HOST=127.0.0.1
REDIS_PORT=6379
```

Создайте базу данных, затем выполните миграции и начальное наполнение:

```bash
php artisan migrate --seed
npm run build
php artisan serve
```

Для фоновой обработки уведомлений в отдельном терминале запустите:

```bash
php artisan queue:work
```

Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000).

После запуска сидера доступен демонстрационный администратор: `admin@example.com` / `password`. Эти данные предназначены только для локальной демонстрации; в общедоступном окружении пароль необходимо заменить.

Для разработки интерфейса вместо `npm run build` можно запустить Vite:

```bash
npm run dev
```

## Docker Compose

Файл `docker-compose.yml` содержит сервисы PostgreSQL, Redis и базовый сервис приложения. Для отдельного запуска инфраструктуры:

```bash
docker compose up -d postgres redis
```

> Текущий сервис `app` использует базовый образ `php:8.3-apache`. В нём заранее не установлены Composer, Node.js и все необходимые PHP-расширения, поэтому сценарий полного запуска приложения одной командой `docker compose up` пока не гарантируется. Для воспроизводимого локального запуска используйте инструкцию выше либо подготовьте отдельный Dockerfile приложения.

## Тестирование

```bash
php artisan test
```

Тесты находятся в `tests/Feature` и `tests/Unit`. Для тестового окружения проверьте настройки базы данных в `phpunit.xml`.

## Деплой

В репозитории предусмотрен workflow `.github/workflows/deploy.yml`: проверка проекта и развёртывание на VPS через Deployer при обновлении основной ветки. Для реального развёртывания необходимо настроить секреты GitHub Actions, SSH-доступ, production-переменные окружения, HTTPS и внешнее хранилище резервных копий.

Команда резервного копирования:

```bash
php artisan backup:database
```

Срок хранения копий настраивается переменной `BACKUP_RETENTION_DAYS`. Локальный каталог резервных копий не заменяет независимое внешнее хранилище.

## Структура кода

```text
app/
├── Http/Controllers/       # контроллеры веб-приложения
│   ├── Auth/               # регистрация, вход и восстановление пароля
│   ├── ProfileController.php
│   └── Admin/              # пользователи, журнал и настройки
├── Models/                 # модели Eloquent
├── Notifications/          # каналы уведомлений
├── Services/               # бизнес-логика
└── Support/                # вспомогательные классы
resources/js/Pages/         # страницы Vue 3 и Inertia
tests/Feature/              # функциональные тесты
```

## Статус проекта

Это учебно-демонстрационный каркас, написанный по открытому техническому заданию для демонстрации архитектуры, кода и документации. Вёрстка упрощена. Капча реализована как демонстрационная; для production предполагается подключение Яндекс SmartCaptcha. SMS-драйвер является заглушкой, реальный сервис подключается через отдельный драйвер.
